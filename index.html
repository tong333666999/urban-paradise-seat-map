如果你已經知道坐哪區：先去哪裡拿比較順

依你座位圖上的位置推估最近的動線，適合少走冤枉路。

A 區

右上方桌位靠近 Wonderland、脆焠、香鑲。如果你坐 A 區，第一輪可先看右側香氣區有沒有想吃的現炸 / 烤物，再繞去 Wonderland 記甜點，主餐則再回中線或上方主線補齊。

B 區

中央區域最方便，離 Ocean bar、Breeeeeze、Oasis 最近，也是最好啟動海鮮 / 前菜 / 飲品路線的位置。適合先暖身再衝主菜。

Q 區

左半邊桌位靠近 VIVA、快意町，很適合熟食和熱主菜派。若同行有人不想先拿生冷海鮮，從這區起手很順。

R 區

下方座位出發最順的是先經過 Oasis 往中線走，再接 Breeeeeze / Ocean bar，最後視胃口決定往 VIVA 或 Wonderland 收尾。從 R 區建議用「由下往上掃」的方式最省路。

下面幫你整理：要吃什麼、拿什麼、怎麼走

給不同口味的人一條好記的拿餐路線。

1. 初訪不踩雷路線

第一次來、什麼都想吃，但又不想一開始拿太重的人，走這條最穩。

Breeeeeze→ Ocean bar→ VIVA→ 快意町 / 美樂地→ Wonderland→ Oasis
先輕後重、先鹹後甜，最後再喝酒或飲料，最不容易吃到中途卡住。

2. 肉派主攻路線

給喜歡現切肉品、鐵板熱菜、烤物和濃郁口味的人。

VIVA→ 美樂地→ 香鑲→ 脆焠→ Wonderland
肉和炸物都很佔胃，記得每站先小份試吃，不要一口氣全拿滿盤。

3. 海鮮微醺路線

海鮮 / 壽司派，並且想留一點空間給飲品搭配的人。

Ocean bar→ Breeeeeze→ VIVA（海鮮主菜）→ Oasis→ Wonderland
這條適合邊吃邊聊，最後再搭配一杯飲品，節奏會很舒服。

4. 長輩 / 穩健熟食路線

如果同行有人偏好熟食、台式菜或不愛太生冷，這條最穩。

快意町→ VIVA→ 美樂地→ 香鑲→ Wonderland
熟食先行最有安全感，也較方便快速找到多數人都能接受的餐點。

我幫你整理的實用提醒

1) 先看一圈再拿。 先知道每區在賣什麼，才不會第一輪就把胃量用光。

2) 炸物、烤物趁熱吃。 脆焠、香鑲最好少量多次，口感差很多。

3) 甜點最後集中拿。 Wonderland 放最後，拍照也比較完整。

4) 酒飲放中後段。 Oasis 很適合聊天或收尾，不建議一開局就靠飲料把胃撐住。

5) 全桌分工最有效率。 一人先拿海鮮、一人拿主菜、一人去看炸烤，回桌再分享最不浪費時間。
